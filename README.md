# Portfólio Pessoal – William Dev

Este projeto foi desenvolvido como parte do aprendizado prático em JavaScript no curso de Sistemas de Informação e servirá como um repositório vivo das minhas experiências e projetos.

Você pode acessá-lo em: [www.willliam.dev](https://www.willliam.dev)

## Funcionalidades


- Navegação dinâmica entre seções com JavaScript (Fetch API AJAX)
- Integração com [FormSubmit](https://formsubmit.co/) para envio de mensagens por formulário.
- Página de contato funcional com redirecionamento pós-envio.
- Design responsivo e layout inspirado no portfólio da [Brittany Chiang](https://v4.brittanychiang.com/)
